2. **2nd Generation​** (1956-1963)​ Transistors​
3. **3rd Generation**  (1964–1971)​ Integrated Circuits
4. **4th Generation** (1971–Present) Microprocessors​
5. **5th Generation** (Present and Beyond) Artificial Intelligence
